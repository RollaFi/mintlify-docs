## Welcome to Rolla Pay

Rolla Pay provides a powerful payment processing API that enables you to accept card payments, bank transfers, and mobile money — manage transactions, and handle webhooks seamlessly.

## Supported Payment Methods

<CardGroup cols={3}>
  <Card title="Card" icon="credit-card">
    Visa, Mastercard, and other card networks
  </Card>
  <Card title="Bank Transfer (NGN)" icon="building-columns">
    Direct bank transfers for Nigerian Naira transactions
  </Card>
  <Card title="Mobile Money (GHS, XOF)" icon="mobile">
    Mobile money payments for Ghanaian Cedi and West African CFA franc transactions
  </Card>
</CardGroup>

## Getting Started

1. **Sign up** for a Rolla Pay account
2. **Get your API keys** from the dashboard
3. **Make your first API call** using our examples

## Base URL

All API requests should be made to:

```
https://api.rollapay.com
```
