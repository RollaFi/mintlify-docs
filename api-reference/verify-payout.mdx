## Overview

Retrieve the current status and details of a payout using its reference. Use this to confirm a payout has been completed, or to check on a pending payout.

## Authentication

| Header | Type | Required | Description |
|--------|------|----------|-------------|
| `Authorization` | string | Yes | Your secret key (`sk_live_xxx`) |

<Note>
No signature is required for GET requests — only the secret key.
</Note>

## Path Parameters

<ParamField path="reference" type="string" required>
  The payout reference returned when the payout was initiated (e.g., `WDR_A1B2C3D4E5F6`).
</ParamField>

## Payout Statuses

| Status | Description | Final? |
|--------|-------------|--------|
| `pending` | Wallet debited, awaiting processor | No |
| `processing` | Sent to processor, awaiting confirmation | No |
| `completed` | Funds delivered to recipient | Yes |
| `failed` | Payout failed, funds refunded to wallet | Yes |

<Tip>
For real-time updates, configure a [webhook](/api-reference/webhooks) instead of polling. You'll receive `payout.completed` or `payout.failed` events as soon as the status changes.
</Tip>
