## Overview

Initiate a bank transfer payment by generating a temporary virtual account. The customer transfers the exact amount from their banking app, and the payment is confirmed automatically once the transfer is received.

No card details are needed — just specify `bank_transfer` as the channel and provide customer information.

<Note>
  Bank transfer is currently available for NGN (Nigerian Naira) payments.
</Note>

## Authentication

All requests must include your secret API key in the Authorization header:

```
Authorization: Bearer sk_live_your_secret_key
```

<Note>
  Use `sk_test_*` keys for testing and `sk_live_*` keys for production.
</Note>

## Request Body

<ParamField body="reference" type="string">
  Optional custom transaction reference. If not provided, a unique reference will be auto-generated (e.g., `TXN_gGbEEvK25eVgmgrf`). Must be globally unique across all transactions.
</ParamField>

<ParamField body="amount" type="number" required>
  The payment amount (e.g., 5000 for 5000 NGN)
</ParamField>

<ParamField body="currency" type="string" required>
  Three-letter ISO currency code. Use `NGN` for bank transfers.
</ParamField>

<ParamField body="channel" type="string" required>
  Must be `bank_transfer`
</ParamField>

<ParamField body="customer" type="object" required>
  Customer information
  <Expandable title="properties">
    <ParamField body="email" type="string" required>
      Customer's email address
    </ParamField>
    <ParamField body="name" type="string">
      Customer's full name
    </ParamField>
    <ParamField body="phone" type="string">
      Customer's phone number
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="callbackUrl" type="string" required>
  URL to redirect the customer after payment completion. Query parameters `reference` and `status` (successful/failed) will be appended.
</ParamField>

<ParamField body="description" type="string">
  Optional description for the payment (max 500 characters)
</ParamField>

<ParamField body="metadata" type="object">
  Additional key-value pairs to attach to the transaction (e.g., order ID)
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  Indicates if the request was successful
</ResponseField>

<ResponseField name="message" type="string">
  Response message
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="properties">
    <ResponseField name="reference" type="string">
      Unique transaction reference (e.g., `TXN_d7WblCDVuoqiQAMB`) or your custom reference if provided
    </ResponseField>
    <ResponseField name="status" type="string">
      Transaction status. Will be `pending` — waiting for the customer to transfer.
    </ResponseField>
    <ResponseField name="account_number" type="string">
      Virtual account number the customer should transfer to
    </ResponseField>
    <ResponseField name="bank_name" type="string">
      Bank name for the virtual account (e.g., "NET Microfinance Bank")
    </ResponseField>
    <ResponseField name="account_name" type="string">
      Account name for the virtual account
    </ResponseField>
    <ResponseField name="account_type" type="string">
      Type of virtual account: `dynamic` (expires after timeout)
    </ResponseField>
    <ResponseField name="amount" type="number">
      Exact amount the customer must transfer
    </ResponseField>
    <ResponseField name="expires_at" type="string">
      ISO 8601 timestamp when the virtual account expires (e.g., `2026-07-23T12:30:00.000Z`)
    </ResponseField>
  </Expandable>
</ResponseField>

## Next Steps

After initiating a bank transfer, the response status will be `pending`. Here's how to complete the payment:

### 1. Display the virtual account details
Show the customer the account they need to transfer to:
- **Account Number** — `account_number`
- **Bank Name** — `bank_name`
- **Account Name** — `account_name`
- **Amount** — `amount` (the customer must transfer the exact amount)

### 2. Show the expiry countdown
Use `expires_at` to display a countdown timer. The virtual account is only valid until this time.

### 3. Customer transfers from their bank
The customer opens their banking app and transfers the exact amount to the virtual account.

### 4. Poll for payment confirmation
Poll the [Verify Transaction](/api-reference/verify-transaction) endpoint every 3-5 seconds to check if the payment has been received. Once `status` changes to `successful`, the payment is complete.

### 5. Webhook notification
You will also receive a [webhook](/api-reference/webhooks) notification when the payment is confirmed.

<Warning>
  Bank transfer virtual accounts expire after 30 minutes by default. If the customer does not transfer within this window, the transaction will expire and a new one must be initiated.
</Warning>
