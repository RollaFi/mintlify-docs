## Overview

Returns the balance of your wallet in one currency. A live key returns your live wallet, a test key your test wallet.

Check the balance before sending a payout or a bulk payout, so you know the wallet can cover it.

## Authentication

| Header | Type | Required | Description |
|--------|------|----------|-------------|
| `Authorization` | string | Yes | Your secret key (`sk_live_xxx`) |

## Path Parameters

<ParamField path="currency" type="string" required>
  The wallet's currency, e.g. `NGN`.
</ParamField>

<RequestExample>
```bash cURL
curl -X GET "https://api.rollapay.com/wallets/NGN" \
  -H "Authorization: Bearer sk_live_your_secret_key"
```

```javascript Node.js

```

## Response

<ResponseField name="success" type="boolean">
  Indicates if the request was successful.
</ResponseField>

<ResponseField name="message" type="string">
  `Wallet retrieved`, or the reason the request failed.
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="properties">
    <ResponseField name="currency" type="string">
      Currency code.
    </ResponseField>
    <ResponseField name="available_balance" type="number">
      What you can pay out now, in major units (e.g. `250000.5` means ₦250,000.50). This is `ledger_balance` less any amount on hold.
    </ResponseField>
    <ResponseField name="ledger_balance" type="number">
      Everything in the wallet, including any amount on hold.
    </ResponseField>
    <ResponseField name="status" type="string">
      `active`, `frozen` or `closed`. Only an `active` wallet can be paid out from.
    </ResponseField>
    <ResponseField name="mode" type="string">
      `live` or `test`, matching your key.
    </ResponseField>
    <ResponseField name="updated_at" type="string">
      When the wallet last changed (ISO 8601).
    </ResponseField>
  </Expandable>
</ResponseField>
